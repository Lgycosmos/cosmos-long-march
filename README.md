# 2026迎新晚会 · 重走长征路 · 青春再出发

一个为校园迎新活动设计的多人互动游戏。参与者使用手机加入活动并完成互动，大屏实时展示活动进度和排名，管理员通过后台统一管理活动。

项目目前已完成问题修复和功能调整，现已可以正常运行，并已部署到 Runway 云服务器。参与者、现场大屏和管理员均可通过浏览器访问对应页面。

## 项目简介

本项目服务于校园迎新活动现场，围绕“重走长征路”主题设计互动体验。参与者通过手机进入活动、填写昵称并参与游戏；现场大屏展示游戏状态和排行榜；管理员可以控制活动开始、暂停和结束，并查看参与数据。

系统主要包含三个页面：

- **参与者页面**：手机扫码或打开链接加入活动，填写昵称并参与互动。
- **现场大屏页面**：展示活动状态、参与情况和排名，供现场观众观看。
- **管理员页面**：管理活动、控制游戏流程、查看成绩并导出数据。

## 主要功能

- 活动房间和活动码管理。
- 手机端加入活动及参与互动。
- 现场大屏展示活动状态和排行榜。
- 管理员统一控制游戏开始、暂停和结束。

- 为现场活动提供扫码加入和手机操作流程。

## 页面入口

部署完成后，请将以下地址替换为 Runway 云服务器上的实际域名：

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| 现场大屏 | `/screen?room=活动码` | 展示活动进度和排名 |
| 参与者入口 | `/join?room=活动码` | 供参与者加入活动 |
| 管理后台 | `/admin` | 管理活动和控制流程 |

例如，活动码为 `2026` 时，大屏和参与者页面可分别使用：

- `https://你的域名/screen?room=2026`
- `https://你的域名/join?room=2026`
- `https://你的域名/admin`

请以实际部署配置为准。管理后台应仅提供给活动工作人员使用。

## 技术栈

项目源码和配置中使用了以下技术：

- **React**：构建交互式页面。
- **TypeScript**：为前端和应用代码提供类型检查。
- **Next.js / vinext / Vite**：应用框架与开发、构建工具。
- **Node.js**：运行应用及相关脚本。
- **SQLite**：保存应用数据。
- **Drizzle ORM**：管理数据库访问和结构迁移。
- **Tailwind CSS**：编写界面样式。
- **Runway 云服务器**：当前部署和运行应用的云服务器平台。
